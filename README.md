# 阿師快炒

3D 快炒店網頁遊戲。晚上五點開店，客人會一直點菜，照單下料、甩鍋、用鍋鏟翻炒，大火甩出鍋氣再出菜。打烊後用賺來的錢換更好的鍋、加開第二口爐、買油炸鍋、升級店面。

**直接玩：** https://a112070044.github.io/kuaichao/

## 玩法

- 點一張點菜單，選你要炒的那道。紅點＝還缺的料。
- 炒鍋：往上滑甩鍋，按住拖曳用鍋鏟翻炒。
- 炸鍋：放料 → 裹地瓜粉 → 往下滑放籃子 → 炸到金黃 → 往上滑拉起、點一下甩油 → 撒胡椒鹽。
- 電腦：空白鍵甩鍋（Shift＋空白大力甩）、Enter 出菜、1／2／3 切換爐子。

存檔只存在你自己的瀏覽器裡。

整個遊戲就是一個 `index.html`，3D 畫面用 [three.js](https://threejs.org/)（r128，從 cdnjs 載入）。
